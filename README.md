# Bộ đề trắc nghiệm pháp luật

## Chạy trên máy bằng VS Code
1. Giải nén thư mục dự án.
2. Mở thư mục `bo-de-trac-nghiem` bằng VS Code.
3. Cài extension **Live Server**.
4. Mở `index.html`, nhấn chuột phải và chọn **Open with Live Server**.

## Chức năng
- Chọn từng bộ đề 10 câu hoặc gộp 5 bộ thành đề tổng hợp 50 câu.
- Cài thời gian thi từ 1 đến 300 phút (mặc định 60 phút).
- Hết giờ tự động nộp bài.
- Sau khi nộp: đáp án đúng màu xanh, đáp án đã chọn sai màu đỏ; phần tổng kết cũng tô màu từng câu.
- Câu chưa xác minh được đánh dấu riêng và không tính vào điểm.

## Đưa lên GitHub Pages
Đẩy cả `index.html`, `questions.json` và `README.md` lên repository, sau đó vào **Settings → Pages → Deploy from a branch**, chọn nhánh `main` và thư mục `/ (root)`.
